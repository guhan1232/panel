01

技术选型与迁移策略

从 Element Plus 换成 Ant Design Vue

项目是 Vue 3 单页应用，因此「Ant Design」采用官方 Vue 实现 ant-design-vue 4.2.6（换 React 版等于重写整个前端框架，会破坏既有功能范围）。Element Plus 及其 CSS 已从依赖、入口与全部模板中移除；现在所有实际渲染的组件都来自 Ant Design Vue。

迁移的三条原则

底层真换18 个视图的 600 多处 el-* 标签全部改成 a-* / Wm*；npm 中已无 element-plus
逻辑不动所有 <script setup> 里的 API 调用、状态与方法逐字保留，只把 ElMessage / ElMessageBox / 图标的 import 指向兼容层
契约保留路由路径、导航文案、表单字段、RBAC、审计逻辑与 wm_theme 持久化键不变

兼容层做了什么

src/antd-compat.ts
ElMessage转发到 antdv message
ElMessageBox.confirm基于 Modal.confirm，返回 Promise，取消时 reject
ElMessageBox.promptModal.confirm + 响应式输入框，返回 { value }
图标别名Element 图标名映射到 @ant-design/icons-vue 同名导出
v-loading自定义指令，用遮罩与旋转指示器替代

表格的迁移方式

Element Plus 用 <el-table-column> 子组件声明列，Ant Design 用 columns 配置。为保留 123 处列模板不重写，新增了 WmColumn（只携带列定义，不渲染 DOM）与 WmTable：后者读取默认插槽里的列 vnode，把 label / prop / width / fixed 和 #default="{ row }" 作用域插槽转成 a-table 的 columns 与 customRender，并处理选择列、空态、最大高度与横向滚动。截图验证表格、开关、状态印章、操作按钮均正常渲染。

02

页面结构与布局

Ant Design 经典三段式

外壳改为深色 Sider（216px，可折叠 80px）+ 白色 Header（56px）+ 浅灰内容区。导航使用 a-menu 的 inline 模式与分组标题；移动端把同一份菜单放进 a-drawer，并保留底部 4+1 快捷栏。内容区上限 1440px，页面统一为「页眉 → 分区卡 → 操作行 → 表格／表单」。

Sider

深色 #001529，选中项用主色填充；分组标题弱化；折叠后只留图标，移动端整体隐藏并转为抽屉。

Header

折叠按钮、面包屑、连接安全状态、主题切换与用户下拉；窄屏隐藏面包屑，只留页面标题。

Content

白卡片 + 8px 圆角 + 极轻投影；页眉 22px 半粗标题；指标卡四列，平板两列，手机一列。

03

应用商店布局（重点）

从一长条堆叠改成「控制条 + 双栏 + 明细」

原来软件商店把工具条、目录行、运行时、已安装表格全部塞进同一张卡片，纵向一长条，扫读成本高。重写后分成四层：顶部统计与筛选控制条；左侧主栏放可安装软件与运行时卡片；右侧辅栏放已安装实例与下载源／运行环境；底部单独放实例明细表格。软件目录和容器目录都改成卡片网格，支持关键词搜索与来源筛选。

改前

信息结构
一张卡片内 4 个纵向区段，无视觉分组
目录是密集行列表，看不出「商店」属性
统计文字散落在标题右侧，无法一眼比较
没有搜索与来源筛选，模板多时只能逐行找
已安装实例只在底部表格出现，缺少概览

改后

信息结构
顶部控制条：4 个计数 + 搜索框 + 来源分段 + 刷新
左栏 16 格：软件／容器卡片网格（1440px 下三列）
右栏 8 格：已安装列表 + 下载源／运行环境
关键词与「全部／内置／镜像源」本地筛选，实时显示命中数
底部独立「实例明细」表格，保留全部操作按钮

07

响应式与可访问性

三档断点 · 触控目标 ≥ 44px

≥ 1280px

216px Sider；指标卡 4 列；商店卡片 3 列、主栏与侧栏 16:8；图表 1.4:1；内容上限 1440px。

900 – 1279px

指标卡 2 列；商店卡片 2 列；内容留白收窄；表格允许横向滚动并固定操作列。

< 900px

Sider 转 260px 抽屉；底部 4+1 标签；商店双栏堆叠、卡片单列；页眉纵向堆叠；弹窗满宽。

断点实现

@media (max-width: 1279px) { /* 指标 2 列、卡片 2 列 */ }
@media (max-width: 900px)  { /* 抽屉 + 底部栏 + 单列 */ }
@media (max-width: 640px)  { /* 触控 44px / 弹窗满宽 */ }
@media (prefers-reduced-motion: reduce) { /* 关闭动效 */ }

可访问性

焦点全局 :focus-visible 2px 主色焦点环
语义导航用 a-menu 与选中态；提示条 role="status"；进度条 role="progressbar"
触控底部栏项 ≥ 44px；viewport-fit=cover 与 env(safe-area-inset-bottom)
暗色ConfigProvider darkAlgorithm + 自定义变量同步切换
